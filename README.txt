APPVAULT LANDINGPAGE
====================

Enthalten:
- index.html               Premium Landingpage (Deutsch)
- datenschutz.html         Datenschutzerklärung (Deutsch)
- privacy.html             Privacy Policy (Englisch)
- styles.css / script.js   Design und Interaktionen
- assets/                  Icon, Screenshots, Feature Graphic (1024x500)

WICHTIG VOR DEM VERÖFFENTLICHEN
1. Datenschutz-Kontakt: flondy.dev@gmail.com
2. English privacy contact: flondy.dev@gmail.com
3. Prüfen, ob der Play-Store-Paketname dev.flondy.appvault korrekt ist. Falls nicht, die URL in index.html ändern.
4. Falls du NICHT GitHub Pages verwendest, den Hosting-Abschnitt in beiden Datenschutzseiten anpassen.
5. Wenn AppVault später Werbung, Analytics, Crash-Reporting, Login, Cloud-Sync oder weitere SDKs nutzt, Datenschutzerklärung und Play-Console-Datensicherheit aktualisieren.

DEPLOYMENT GITHUB PAGES
- Alle Dateien in ein GitHub-Repository kopieren.
- Repository Settings > Pages > Deploy from a branch > main / root.
- Danach in der Play Console die öffentliche URL zu datenschutz.html als Datenschutzerklärung eintragen.

Hinweis: Die Landingpage selbst lädt keine externen Fonts, setzt keine Cookies und verwendet kein Analytics.
